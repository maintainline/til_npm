# Kakao Map

- https://developers.kakao.com/
- 참조 : https://velog.io/@tpgus758/React에서-Kakao-map-API-사용하기

## 1. API 신청하기

- 환경 설정 내용

```
REACT_APP_KKO_MAP_REST_API_KEY=
REACT_APP_KKO_MAP_JS_API_KEY=
```

- 웹 플랫폼 설정 (등록)

```
http://localhost:3000
http://localhost:5173
```
